# Dharshini Portfolio

Premium dark cinematic personal portfolio built with React, TypeScript, Vite, Motion and Lucide.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main features

- Cinematic hero with portrait, halo, particles and pointer-reactive depth
- Fixed-size white cinematic cursor that never expands on hover
- Interactive knowledge graph
- Skills and project showcases
- Full-screen project case studies
- "Meet Ms. Dharshini" portfolio guide
- Developer terminal Easter egg
- Six-step build process section
- Responsive contact flow with email and WhatsApp
- Reduced-motion support

Edit personal content in `src/data/site.ts` and `src/data/content.ts`.
